# 💰 マイ決算書

カード明細（PDF/CSV）を自動仕分けし、会社の決算書のように
**自分専用のP/L（損益計算書）とB/S（貸借対照表）** で家計を見える化する、
無料の家計簿・資産管理アプリ（PWA）。

> 💸 **完全無料・広告なし・登録不要**：すべての計算・仕分け・コメント生成は
> 端末内（ブラウザ）で完結します。外部APIや有料サービスは一切使わず、
> データは端末の localStorage にのみ保存されます（外部送信なし）。

## 📲 使いはじめる
1. アプリのURLをスマホで開く
2. ホーム画面に追加（**iPhone**: Safari→共有→ホーム画面に追加 / **Android**: Chrome→⋮→ホーム画面に追加）
3. あとはアプリ内の「👋 3ステップガイド」に沿って明細を取り込むだけ

## 🔒 プライバシー
- 入力・取込した家計データはすべて端末内のみ。開発者を含む第三者に送信されません
- Cookie・アクセス解析・広告なし。詳細はアプリ内「設定 → プライバシーポリシー・免責事項」

## 🛠 セルフホストする場合（Netlify）
1. このリポジトリをフォーク/アップロード（Private推奨）
2. [app.netlify.com](https://app.netlify.com) → Add new site → Import an existing project → リポジトリを選択
3. Build command: `npm run build` / Publish directory: `.next`（自動検出されます）
4. Deploy site → 1〜2分でURLが発行されます（無料枠で運用可能）

## 機能一覧
- 📑 **マイ決算書**：自分専用の損益計算書(P/L)＋貸借対照表(B/S)を自動生成
- 💎 **資産管理**：預金・株・投信・債券・年金・不動産・暗号資産などを登録
- 💳 **負債管理**：住宅/自動車ローン・奨学金・カード残高などを登録
- 🧮 **純資産（ネットワース）**：総資産−負債を自動計算し、推移グラフで可視化
- 💼 収入管理（給与・副業・賞与・投資収益）
- 💸 支出の手入力（連続入力対応）＋明細アップロード（CSV / PDF）＆自動カテゴリ分類
- 🔁 明細は重複を自動スキップして蓄積。**日付どおりの月へ自動振り分け**（月またぎ明細もOK）
- 🧠 仕分けの学習：カテゴリを1回直せば同じ店は次回から自動。学習ルールの管理画面つき
- 🏷️ **カテゴリのカスタム**：自作カテゴリの追加、標準カテゴリの絵文字・色・固定/変動の変更
- 📊 固定費vs変動費、カテゴリ別分析、年間累計（収入・支出の累計推移）、貯蓄率の推移
- 🆚 **月の比較**：好きな2ヶ月をカテゴリ別に見比べ
- 🗓 支出カレンダー（日別ヒートマップ）＆ 🔁 固定費・サブスク一覧（年換算つき）
- 🔍 明細の検索（全期間横断も可）・カテゴリ絞り込み・並び替え・編集・削除
- 🎯 貯金目標＆純資産目標＆進捗バー
- 💬 スマートコメント（前月比・貯蓄率・予算・週末の傾向・純資産の進捗から自動生成。端末内で完結・外部送信なし）
- 📏 月の予算（全体＋カテゴリ別）。残り額と「1日あたり使えるペース」を表示
- 🏅 実績バッジ（連続黒字・記録継続・純資産過去最高）でモチベーション維持
- 💾 データのバックアップ（JSON）＋明細のCSV書き出し（Excel用）
- 📲 PWA対応（ホーム画面追加で独立起動・専用アイコン付き）

## 📑 決算書の見方
- **損益計算書（P/L）**：その期間に「いくら稼ぎ・いくら使い・いくら残ったか」（収益／費用／当期純利益）
- **貸借対照表（B/S）**：今この瞬間に「いくら持ち・いくら借りているか」（資産＝負債＋純資産）

資産・負債は「資産」タブから登録・更新でき、純資産の推移が自動で記録されます。
